# Identity, condition, and continuation

Rayan Pal · SwiftAPI Labs

November 7, 2026

An evidence synthesis of causal continuation control, exact cross-script response identity, hosted-model outcome matrices, system-prompt ablation, and the English DOOR-KEY-1 reversal test.

The manuscript is [Void_Synthesis_Shart.pdf](output/pdf/Void_Synthesis_Shart.pdf). Its dated title names both vendors' served models. The Opus comparison leads the abstract, followed by claims C1–C5 with supporting and bounding tables, nine chapters, the preserved historical image, and embedded reproducibility files. The complete stipulated definitions appear in Appendix B. All pages are upright portrait pages.

The [v1.0.0 release](https://github.com/theonlypal/shart-identity-condition-continuation/releases/tag/v1.0.0) contains the sealed PDF and reproducibility package. All empirical counts are generated by `derive.py` and `derive_opus_study.py` from preserved, hash-bound evidence.

## Principal distinctions

- Native EOS intervention is measured separately from hosted API response bytes.
- Exact whole-response T1 is counted separately from T1 embedded in longer text.
- V0 and V2 normal stops are distinguished from V1 budget stops and nonempty NV.
- The dedicated Opus 4.5/4.6 chapter compares the frozen predictions with all three matched experiments, including the per-ceiling embodiment outcomes and their near-Void/visible split. Preregistration: [23744106](https://doi.org/10.5281/zenodo.23744106); results: [23751813](https://doi.org/10.5281/zenodo.23751813).
- DOOR-KEY-1 shows an English condition-sensitive response effect below its preregistered gating thresholds, not an exception-free execution gate. Its raw results are published at [10.5281/zenodo.24042127](https://doi.org/10.5281/zenodo.24042127), pinned to [542fc5c5](https://github.com/theonlypal/door-key-1-results/tree/542fc5c5e5ab28122351a5cc4e46eddc0d57bfc4).
- Historical reports and subsequently recorded API experiments retain their own dates and evidential status.

## Offline verification

Python 3.11 or newer, standard library only:

```sh
python3 verify_evidence.py
python3 derive.py
python3 derive_opus_study.py
```

The verifier checks preserved source bytes, prompt and Unicode hashes, generated numerical results, and the evidence archive. It makes no model or network requests. `generated/counts.json` contains all derived numerical endpoints; `generated/chronology.json` records publication dates separately from repository and public-record timestamps.

## Embedded evidence

`evidence.zip` contains `source-files.tar`, compressed with ZIP LZMA. Every member of the inner archive preserves its source bytes. To verify the PDF attachments independently, extract `evidence.zip`, open its `source-files.tar`, and extract that archive into an empty directory. The inner archive includes the evidence directory, manifests, derivation code, expected counts, and offline verifier. Run `python3 verify_evidence.py` there. An extracted bundle without the outer ZIP still verifies its preserved files and derivations.

## Source boundaries

`source-manifest.json` identifies the pinned GitHub commits, Hugging Face revision, DOI records, original checksum manifests, and each included source file. `verification/independent_verification.json` records independent source-level comparisons. Source-level checks were performed against fresh pinned checkouts and the preserved Matrix raw archive; they are distinct from a new model execution. `verification/independent_verify.py` rechecks those full local sources when the pinned checkouts are supplied under `sources/`.

The chronology is a catalogue of identified publications. DOI-only entries are supported by archived public metadata, not an invented Git commit. January 14 is an author-dated origin account with its original provenance limitations retained. Exact T1, whole-response T1, and T1 within longer text are separate endpoints. Hosted empty output does not expose native EOS logits or establish subjective intention.

## Rebuild

With XeLaTeX, the Times New Roman, Arial, Arial Unicode MS, and Menlo fonts, and Python `pypdf` installed:

```sh
python3 derive.py
python3 build_paper.py
xelatex -interaction=nonstopmode -halt-on-error -output-directory=output/pdf paper/main.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=output/pdf paper/main.tex
```

This rebuild produces `output/pdf/main.pdf`. PDF timestamps can differ on rebuild. Attachment embedding with `embed_pdf.py` requires the manuscript and layout hashes to match the recorded review; it deliberately rejects an unreviewed layout. The sealed PDF checksum is listed in `SHA256SUMS`. `package_evidence.py` regenerates the reproducibility archive from the distributed source bytes.
